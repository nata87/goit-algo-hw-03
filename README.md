# Домашнє завдання №3: Рекурсивні функції, алгоритми та приклади їх застосування

## 📂 Структура завдання

 Завдання включає реалізацію рекурсивного копіювання файлів із сортуванням за розширенням, а також побудову фракталу сніжинки Коха з використанням рекурсії.

---

### ✅ Завдання 1: Рекурсивне копіювання та сортування файлів


Скрипт рекурсивно читає вміст вихідної директорії, копіює всі файли у нову директорію (за замовчуванням `dist`) і сортує їх за розширеннями у відповідні підтеки.

### Функціональність

- Приймає два аргументи командного рядка:
  - `source_dir` – шлях до вихідної директорії.
  - `destination_dir` – шлях до директорії призначення (необов’язковий, за замовчуванням `dist`).
- Рекурсивно обходить всі підтеки.
- Копіює кожен файл у піддиректорію нової теки відповідно до його розширення.
- Обробляє винятки, пов’язані з доступом до файлів та директорій.

**Файл:** `task_1.py`

### Запуск

```bash
python task1.py "path/to/source" "path/to/destination"
```
Перший аргумент — існуюча папка з файлами (наприклад, test).
Другий аргумент — місце, куди копіювати файли (не обов’язковий, якщо не вказаний — буде dist).

### ✅  Завдання 2: Побудова фракталу «Сніжинка Коха»

Програма рекурсивно будує фрактал сніжинки Коха, використовуючи бібліотеку turtle. Користувач самостійно вводить рівень рекурсії, що визначає деталізацію сніжинки.

### Функціональність
- Візуалізує фрактал за допомогою графіки.
- Приймає рівень рекурсії як введення користувача.
- Працює рекурсивно: на кожному рівні замінює відрізок трьома новими, утворюючи сніжинку.

### Запуск
Запусти в терміналі або в IDLE:

```bash
import turtle
turtle.forward(100)
```

```bash
python task2.py
```
